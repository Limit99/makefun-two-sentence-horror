# Do Not Trust This Version

A tiny Node/TypeScript program for the make.fun bounty "Two-Sentence Horror". It writes a two-sentence horror story to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), after validating that the line is a single non-empty line of at most 400 characters.

Entry line:

> The update finished at 3 a.m. and the house went quiet — every screen dark, every light out, except the fridge, which hummed my name. I opened the door, and the note inside said: do not trust the version that wrote this.

Run it with: `node main.ts`
